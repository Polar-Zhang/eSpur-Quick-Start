# Waveshare 2.4寸 SPI LCD 接线指南

> 2026-11-02 在 eSpur-Studio(新 lab 机,Pi 4B / trixie)实机接线验证通过,全流程(LCD → fbcp → 控制台镜像)跑通。
> 本文是接线快速参考;配置流程见同目录 `SKILL.md`,完整原理与踩坑见 `SPI-LCD配置完全手册.md`。

## 接线对应表(实机验证版)

**按丝印找线,不要按位置**。「实际线色」为本次部署所用杜邦线颜色,可对照核查:

| 屏幕丝印 | 含义 | GPIO(BCM) | 物理引脚 | 实际线色 |
|---|---|---|---|---|
| **VCC** | 电源 3.3V | — | **1** | 紫 |
| **GND** | 地 | — | **6** | 白 |
| **DIN** | SPI MOSI | GPIO10 | **19** | 绿 |
| **CLK** | SPI SCLK | GPIO11 | **23** | 橙 |
| **CS** | 片选 CE0 | GPIO8 | **24** | 黄 |
| **DC** | 数据/命令 | GPIO25 | **22** | 蓝 |
| **RST** | 复位 | GPIO27 | **13** | 棕 |
| **BL** | 背光 | **GPIO18** | **12** | 灰 |

⚠️ BL 刻意接**物理 12(GPIO18)**,不是驱动源码定义的 GPIO24(物理 18)——原因见下节。

## 背光接法:物理 12(本项目标准)vs 物理 18

| 接法 | 行为 | 适用 |
|---|---|---|
| **物理 12(GPIO18)** ✅ 实机采用 | 背光**常亮**,不受控制台息屏影响 | 无人值守状态屏(本项目场景) |
| 物理 18(GPIO24,源码默认) | fbcp 接管背光,**控制台息屏时会被关掉**,屏幕变黑 | 需要自动息屏省电时 |

setup.sh 编译的 fbcp 带 `BACKLIGHT_CONTROL=ON`(驱动 GPIO24)。接 12 时该控制不生效,背光由模块侧保持常亮——图像、背光实测均正常。另注:BL 悬空时模块默认上拉也会常亮,但按表接 12 更规范。

## 数对法:杜绝数错引脚

实机调试中 BL 线曾两次插错(物理 31、物理 11),根因都是逐个数脚数岔了。用「数对法」不会错:

1. 排针**靠 SD 卡槽的角**是起点;板背 **1 脚焊盘为方形**(其余圆形),可验证方向没反
2. 每对 = 相邻上下两个脚,从 SD 角开始**一对一对数**:**第 N 对 = 物理 2N-1 和 2N**
3. **和 1 脚同排 = 奇数脚;和 2 脚同排 = 偶数脚**

本屏 8 根线的对位:

| 丝印 | 对位 | 丝印 | 对位 |
|---|---|---|---|
| VCC | 第 1 对·奇(1) | RST | 第 7 对·奇(13) |
| GND | 第 3 对·偶(6) | DIN | 第 10 对·奇(19) |
| BL | 第 6 对·偶(12) | DC | 第 11 对·偶(22) |
| — | — | CLK+CS | **第 12 对**·奇上偶下(23/24) |

注意 BL 曾插在物理 11——正是**第 6 对选错了排**(11 是奇排,12 才是偶排);CLK 和 CS 在同一对里,一上一下,别漏一根。

- MISO(物理 21)本屏不需要,屏幕无法回读数据(单向)

## 接线注意事项

1. **先关机再接线**(`sudo shutdown now`),插完再上电
2. **VCC 只接 3.3V(物理 1),绝不接 5V(物理 2/4)**——接 5V 会烧屏
3. 信号线插错不会坏,只是不显示;插好上电,fbcp 开机自启,**出控制台文字即全对**
4. **fbcp 跑起来之后不要再动任何 GPIO 的模式**(见排障速查最后一条)

## 排障速查

| 症状 | 判定与处理 |
|---|---|
| 背光常亮但无图像 | 信号线(DIN/CLK/CS/DC/RST)错位。`systemctl is-active fbcp` + `journalctl -u fbcp -b` 确认 fbcp 在跑;按数对法重核五根线 |
| 完全无背光 | VCC/GND/BL 问题:VCC 是否物理 1(3.3V)、GND 是否插紧、丝印是否认错 |
| 背光不受控制、一直亮 | 本项目标准接法(物理12)就是常亮,属预期行为 |
| BL 线不知道插哪去了 | **先停 fbcp**(`sudo systemctl stop fbcp`),再逐脚下拉扫描:`pinctrl set <gpio> ip pd; pinctrl get <gpio>`,读 hi 的脚就是 BL(实机曾据此定位误插的物理31/物理11)。插在电源轨或悬空则探不到 |
| 屏幕突然黑(之前正常) | ① 是否有人动过引脚模式?fbcp 运行中用 pinctrl 扫描/改模式会把 SPI 三线(GPIO8/10/11)从 ALT0 改成 input,**当场断总线黑屏**(2026-11-02 实锤)② 恢复:`pinctrl set 8 a0; pinctrl set 10 a0; pinctrl set 11 a0; pinctrl set 24 op; pinctrl set 25 op; pinctrl set 27 op`,之后**仍黑则必须** `sudo systemctl restart fbcp` 重跑初始化——总线断期间屏幕控制器可能被垃圾数据卡死,光恢复引脚救不回来 |
